# Proposal

## Why

AssetForge 的界面文字目前主要硬编码为土耳其语，英语和简体中文用户无法顺畅使用各页面及其操作。需要在设置中提供语言选择，并完整覆盖应用自己呈现的可见文字，而非只翻译首页和导航。

## What Changes

- 在设置页增加始终可发现的界面语言选择：English、简体中文、Türkçe；切换即时生效并持久保存。
- 新增英语、简体中文完整词典，保留土耳其语；未设置语言时根据系统语言选择，其他语言回退英语。
- 覆盖导航、全部功能页、设置子面板、列表选项、右键/托盘菜单、弹窗、按钮、提示、占位符、辅助标签、应用生成的状态/校验错误，以及共享元数据和第三方画布控件。
- 保持项目数据、用户输入、协议字段、内部状态与标识、模型生成内容及外部工具原始输出不因切换语言而改写。应用对外部错误的说明需本地化。
- 提供界面文字审计清单、词典一致性与交互验证，防止遗漏和回归。

## Capabilities

### New Capabilities

- `interface-localization`: 语言选择及保存、全界面本地化、跨进程显示消息、兼容既有数据及语言覆盖验证。

### Modified Capabilities

无。当前没有已有 capability spec。

## Impact

- React/Electron 桌面应用，以及复用 renderer 的浏览器界面与登录/邀请页面。
- `src/renderer/src/` 的 App、store、10 个页面和相关组件；`src/shared/` 中的显示元数据；`src/main/` 中的设置、原生菜单/对话框、Web 页面与面向用户的错误消息；preload/HTTP 消息契约。
- 新增轻量、类型安全、可跨 renderer/main 使用的本地化模块，不计划新增运行时依赖。
- 增加 locale 设置字段和可选的结构化显示消息，向后兼容现有项目和设置；不更改 AI 服务提示词策略、生成内容语言或安装器语言。本次不修改业务功能。
- 界面覆盖及实际验收步骤见 `ui-audit.md`；代码审计已完成，尚未运行应用进行视觉验收。
